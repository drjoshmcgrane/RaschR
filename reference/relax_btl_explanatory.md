# Add a fixed object departure to an explanatory comparative judgement model

Add a fixed object departure to an explanatory comparative judgement
model

## Usage

``` r
relax_btl_explanatory(fit, object)
```

## Arguments

- fit:

  A fitted object from
  [`btl_explanatory`](https://drjoshmcgrane.github.io/rasch/reference/btl_explanatory.md).

- object:

  Object name.

## Value

A refitted explanatory comparative judgement model.
